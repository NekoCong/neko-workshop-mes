前端运行与构建（灵喵工坊 MES）：

基础命令（在本目录执行）：
1、安装 Node 18 及以上（已在 Node 24 验证）
2、npx pnpm@7.33.6 install
3、修改 .env.dev 中的 VITE_BASE_URL、VITE_UPLOAD_URL 为你的服务端 API 地址
4、本地测试：npx pnpm@7.33.6 dev
5、如果要打包正式版，先确认 .env.prod 中的 VITE_BASE_URL、VITE_UPLOAD_URL 指向你的服务端 API 地址，再执行：
   npx pnpm@7.33.6 build:prod

说明：build:prod 使用 --mode prod，读取 .env.prod；默认 VITE_OUT_DIR=dist。构建产物输出在本目录 dist/。

如果运行、构建时报错，按照以下方式操作：
1、安装 Node 18 及以上
2、安装 npm install -g pnpm@7.33.6（如果已装过其他版本 pnpm，先执行 npm uninstall -g pnpm）
3、清理缓存 pnpm store prune
4、执行 pnpm install --frozen-lockfile
5、修改 .env.dev 中的 VITE_BASE_URL、VITE_UPLOAD_URL 为你的服务端 API 地址
6、pnpm dev
7、如果要打包正式版，确认 .env.prod 配置后执行 pnpm build:prod
